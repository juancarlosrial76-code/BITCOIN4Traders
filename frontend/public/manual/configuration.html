Bot-Parameter und Einstellungen anpassen

Bot-Einstellungen

Konfigurieren Sie die grundlegenden Trading-Parameter:

Parameter Beschreibung Standard
symbol Trading-Paar (z.B. BTCUSDT) BTCUSDT
timeframe Zeitrahmen für Kerzen (1m, 5m, 15m, 1h, 4h, 1d) 1h
maxPositions Maximale Anzahl offener Positionen 3
agentType RL-Algorithmus (PPO, A2C, DQN, TD3) PPO

Risikomanagement

Passen Sie die Risikoparameter an Ihre Risikotoleranz an:

Parameter Beschreibung Standard
maxDrawdown Maximaler Drawdown bevor der Bot stoppt 20%
stopLoss Stop-Loss Prozentsatz 2%
takeProfit Take-Profit Prozentsatz 5%
positionSizePercent Positionsgröße als % des Kapitals 10%

Empfehlung: Ändern Sie die Risikoparameter nur, wenn Sie die Auswirkungen vollständig verstehen. Zu aggressive Einstellungen können zu schnellen Verlusten führen.

Umgebungsvariablen

Für erfahrene Benutzer können zusätzliche Einstellungen über Umgebungsvariablen konfiguriert werden:

# Binance API (Live Trading)
BINANCE_API_KEY=your_api_key
BINANCE_API_SECRET=your_api_secret
BINANCE_TESTNET=false

# Logging
LOG_LEVEL=INFO
LOG_FILE=logs/bt4t.log

# Colab Bridge
BT4T_LISTENER_URL=https://your-url.trycloudflare.com
BT4T_API_TOKEN=bt4t-secret-token

# Server
CORS_ORIGINS=http://localhost:5173,http://localhost:3000
ENVIRONMENT=development
