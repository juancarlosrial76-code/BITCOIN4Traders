Schnellstart

In 5 Minuten mit BITCOIN4Traders starten

Voraussetzungen

  • Python 3.11 oder höher
  • Git (für das Klonen des Repositories)
  • Ein Binance Konto (für Live-Trading)

Installation

1

Repository klonen

git clone https://github.com/juancarlosrial76-code/BITCOIN4Traders.git
cd BITCOIN4Traders
2

Virtuelle Umgebung erstellen

python -m venv venv
source venv/bin/activate  # Linux/Mac
# oder
venv\Scripts\activate     # Windows
3

Dependencies installieren

pip install -r requirements.txt
4

Backend starten

cd backend
uvicorn main:app --reload

Das Backend ist jetzt unter http://localhost:8000 verfügbar.

5

Frontend starten

cd frontend
npm install
npm run dev

Das Dashboard ist jetzt unter http://localhost:5173 verfügbar.

Erste Schritte im Dashboard

1

Anmelden

Öffnen Sie das Dashboard unter http://localhost:5173 und melden Sie sich mit den Standard-Zugangsdaten an:

  • Benutzername: admin
  • Passwort: admin123
2

Dashboard erkunden

Das Dashboard zeigt Ihnen:

  • Live-Preise von BTC/USDT
  • Ihr Portfolio und Kontostand
  • Aktuelle Trading-Signale
  • Performance-Metriken
3

Trading starten

Gehen Sie zur Trading-Seite und klicken Sie auf "Start Bot" um den automatisierten Handel zu aktivieren.

Paper Trading vs Live Trading

Modus Beschreibung Risiko
Paper Trading Simulierter Handel mit virtuellem Geld Keins
Live Trading Echter Handel mit echten Binance API-Keys Hoch

Um Live-Trading zu aktivieren, setzen Sie die Umgebungsvariablen:

export BINANCE_API_KEY="your_api_key"
export BINANCE_API_SECRET="your_api_secret"
export BINANCE_TESTNET="false"
