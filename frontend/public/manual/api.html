API Referenz

Programmatischer Zugriff auf BITCOIN4Traders

Authentication

Die API verwendet JWT (JSON Web Token) für die Authentifizierung.

Login

POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123"
}

Response:
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer"
}

Verwenden Sie das Token in nachfolgenden Requests:

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

Trading API

Status abrufen

GET /api/trading/status

Response:
{
  "is_running": true,
  "current_position": 0.05,
  "unrealized_pnl": 124.50,
  "timestamp": "2024-01-15T10:30:00",
  "champion_signal": "LONG",
  "champion_name": "BollingerScout_v3",
  "mode": "paper"
}

Trading starten

POST /api/trading/start

Response:
{
  "status": "started",
  "timestamp": "2024-01-15T10:30:00",
  "champion": "BollingerScout_v3",
  "initial_signal": "LONG",
  "mode": "paper"
}

Order platzieren

POST /api/trading/order
Content-Type: application/json

{
  "symbol": "BTCUSDT",
  "side": "buy",
  "order_type": "market",
  "quantity": 0.01
}

Response:
{
  "order_id": "PAPER-1705312200",
  "symbol": "BTCUSDT",
  "side": "buy",
  "status": "paper_filled",
  "quantity": 0.01,
  "price": 43000.00,
  "timestamp": "2024-01-15T10:30:00",
  "mode": "paper"
}
