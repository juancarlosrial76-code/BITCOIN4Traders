Allgemeine Fragen

Was ist BITCOIN4Traders?

BITCOIN4Traders ist ein Deep Reinforcement Learning Trading System für Bitcoin. Es kombiniert genetische Algorithmen (Darwin Engine) mit PPO für automatisierte Trading-Strategien.

Ist das System kostenlos?

Ja, das Projekt ist Open Source unter MIT License. Sie können es kostenlos nutzen und modifizieren.

Welche Programmiersprache wird verwendet?

Python für das Backend und Training, TypeScript/React für das Frontend.

Muss ich programmieren können?

Für die Grundnutzung nicht. Für erweiterte Anpassungen sind Python-Kenntnisse hilfreich.

Technische Probleme

1

Backend startet nicht

Symptom: "Module not found" Fehler

Lösung:

  • Stellen Sie sicher, dass alle Dependencies installiert sind: pip install -r requirements.txt
  • Überprüfen Sie die Python Version (3.11+ erforderlich)
  • Installieren Sie fehlende Pakete manuell
2

Frontend lädt nicht

Symptom: Weiße Seite oder Fehler im Browser

Lösung:

  • Führen Sie npm install im frontend-Verzeichnis aus
  • Löschen Sie den node_modules Ordner und installieren Sie erneut
  • Überprüfen Sie die Browser-Konsole für Fehlermeldungen
3

API gibt 401 Fehler zurück

Symptom: "Unauthorized" bei API-Aufrufen

Lösung:

  • Melden Sie sich im Dashboard an
  • Überprüfen Sie, ob das Token im Local Storage vorhanden ist
  • Loggen Sie sich aus und erneut ein
4

WebSocket-Verbindung fehlgeschlagen

Symptom: "Disconnected" Status im Dashboard

Lösung:

  • Überprüfen Sie, ob das Backend läuft
  • Stellen Sie sicher, dass CORS korrekt konfiguriert ist
  • Überprüfen Sie die Netzwerkverbindung
5

Binance API Fehler

Symptom: "Binance API Error" Meldungen

Lösung:

  • Überprüfen Sie Ihre API-Keys
  • Stellen Sie sicher, dass API-Trading aktiviert ist
  • Für Tests verwenden Sie das Testnet: BINANCE_TESTNET=true

Training-Probleme

Problem Ursache Lösung

OOM Fehler Nicht genug RAM/GPU Batch-Size reduzieren
Schlechte Performance Zu wenige Daten Mehr historische Daten laden
Modell lädt nicht Falsches Format .pkl Datei im cache Ordner

Performance-Probleme

Hoher Drawdown

Verringern Sie die Positionsgröße und erhöhen Sie den Stop-Loss.

Zu viele Trades

Erhöhen Sie die Signal-Schwelle in der Konfiguration.

Schlechte Win-Rate

Trainieren Sie das Modell mit aktuelleren Daten neu.
